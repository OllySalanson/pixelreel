Do this once

Add Pixel Reel to Claude

It takes about a minute. It is free. It works on every Claude plan.

  1. 1

    Press the big button

    Claude opens in a new tab, with Pixel Reel already filled in.

    Open Claude and add it

    You may need to sign in to Claude first.

    {{icon:phone:3}}

    On a phone? It is easiest to add it on a computer. After that, it works in the Claude app on your phone too.

  2. 2

    Say yes

    Claude shows a box with Pixel Reel's name and address in it. Follow its buttons to add it: usually Continue, then Add.

    There is no password, and nothing to sign in to.

    Add a connector

    Name

    Pixel Reel

    Address

    {{mcp}}

    Add

  3. 3

    Ask for a reel

    Start a new chat, and say what you want explained. Something like this:

    Say this to Claude

    Make me a pixel reel about how to read my gas meter.

    Help me ask for something else

  4. 4

    Press play

    The reel plays right there in the chat, as soon as the voice is recorded. That takes about as long as the reel itself.

    Want to send it on WhatsApp? Ask Claude for the video.

Plan B

If the big button does not work

You can add it by hand. Same result, a bit more pressing.

  1. In Claude, open Customize, then Connectors.
  2. Press Add, then Add custom connector.
  3. Name it Pixel Reel, and paste in this address: {{mcp}}
  4. Press Continue, then Add.
