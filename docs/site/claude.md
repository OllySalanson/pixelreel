# Add Pixel Reel to Claude

You only do this once, and it works on every Claude plan.

1. In Claude, open **Customize**, then **Connectors**.
2. Add a **custom connector**.
3. Name it **Pixel Reel**, and paste this address: `{{url}}/mcp`
4. Press **Add**. There is nothing to sign in to.

Then ask Claude for a pixel reel about anything: a letter you have been sent, how something
works, a plan, a recipe. Claude writes the scenes, and the reel plays in the chat as soon as
the voice is recorded, which takes about as long as the reel itself. Ask for the video if you
want an MP4 to send on WhatsApp.

On the free Claude plan you can have one custom connector at a time.
