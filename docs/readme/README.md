# The pictures in the README

Every animated picture in the main README is a few seconds of the
[showreel](../../reels/showreel/reel.js), made with the banner maker. To make one again after
changing the scenes it shows, run `npm start`, open
<http://localhost:8000/export.html?reel=showreel>, enter the clips below, press
**Make the banner**, and save the download over the old file.

| File | Clips (scene:from-to) | Frames a second | Detail | Watch button |
| --- | --- | --- | --- | --- |
| `hero.svg` | `2:0.5-2.4, 4:8.35-9.7, 9:6.4-7.6, 8:6.95-8.1, 13:12.0-13.3, 15:3.9-5.4` | 15 | 2x | yes |
| `pictures.svg` | `5:2.3-6.95` | 10 | 1x | no |
| `kit.svg` | `4:3.6-9.6` | 10 | 1x | no |
| `transitions.svg` | `9:0.2-4.5` | 15 | 1x | no |
| `controls.svg` | `8:2.2-8.4` | 10 | 1x | no |

The hero's first frame is also its still picture for anyone who prefers less motion, so it
starts with the logo already on screen.
